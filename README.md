# GSRCBGKL
Goldsrc (Half-Life, Counter-Strike 1.6) Background-maker. Нарезка изображения для фона в игре.  
arbtttrn6, 2026.  
  
  
== RU ==  
  
0) Для чего?  
   0.1) Для нарезки одного изображения формата `png` во множество изображений 
      формата `tga` с созданием файлов `BackgroundLayout.txt` и `HD_BackgroundLayout.txt` 
      для игр на `Goldsrc` (`Half-Life`, `Counter-Strike 1.6`).  
1) Как собрать?  
   1.1) Создать папку `build`;  
   1.2) В папке `build` выполнить `cmake ..`;  
   1.3) В папке `build` выполнить `make`;  
2) Как пользоваться?  
   2.1) Ввести `GSRCBGKL ./image.png`;  
  
== ISV ==  
  
0) Načto?  
   0.1) Zaradi rezanja jednogo obrazka formata `png` vo množstvo obrazkov formata
      `tga` so stvorjenjem fajlov `BackgroundLayout.txt` i `HD_BackgroundLayout.txt` 
      na igry na `Goldsrc` (`Half-Life`, `Counter-Strike 1.6`).  
1) Kako kompilirovati?  
   1.1) Stvoriti papku-direktoriju `build`;  
   1.2) V direktorije `build` izpolniti `cmake ..`;  
   1.3) V direktorije `build` izpolniti `make`;  
2) Kako upotrebjati?  
   2.1) Vpisati `GSRCBGKL ./image.png`;
